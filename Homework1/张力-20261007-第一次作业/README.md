## 三、坐标转换（作业重点）

高德 API 返回的坐标基于 **WGS84 地理坐标系（EPSG:4326）**，经纬度的单位是「度」，无法直接用于长度和面积量算，因此转换为投影坐标系：

- **源坐标系**：`EPSG:4326`（WGS84 经纬度，单位：度）
- **目标坐标系**：`EPSG:3857`（Web 墨卡托投影，单位：米）

转换代码：

```python
gdf_4326 = gpd.GeoDataFrame(df, geometry=..., crs="EPSG:4326")   # 地理坐标系
gdf_3857 = gdf_4326.to_crs(epsg=3857)                            # 投影坐标系
```

**转换结果示例**（南京某大学，第一个点）：

| 坐标系 | X | Y | 单位 |
|---|---|---|---|
| EPSG:4326 | 118.795193 | 32.054213 | 度 |
| EPSG:3857 | 13224220 | 3770429 | 米 |

转换后的坐标已随数据一并导出（见 `数据/POI_EPSG3857投影.csv`）。
