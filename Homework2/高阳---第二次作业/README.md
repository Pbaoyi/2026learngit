**研究题目：俄乌战争背景下乌克兰卡霍夫卡大坝溃决前后水体特征变化——基于 Sentinel-2 的 MNDWI 可视化分析**

## 一、任务

本作业使用 Google Earth Engine（GEE）提供的 Sentinel-2 卫星影像，在 VS Code中，计算并展示卡霍夫卡大坝溃决前后的改进归一化水体指数（MNDWI）。通过采用相同空间范围、相同色带和相同数值范围的两期对比图，观察原水库区域水体光谱特征的变化。

本作业的核心成果是 **MNDWI 连续指数的可视化对比**，包括交互式滑动对比地图和并排 PNG 图片。研究重点是识别和解释原库区水体特征减弱、分布范围收缩等现象，不涉及 NDVI 分析，也未计算水面面积、水量或水深变化。

## 二、研究背景与区域

卡霍夫卡水库位于乌克兰南部第聂伯河上。2023年6月6日，卡霍夫卡大坝毁坏并发生溃决，引起上游水库退水和下游洪水。联合国环境署将其纳入俄乌战争相关环境损害的评估范围，NASA 也通过卫星影像记录了水库退水及库底出露等变化。

## 四、MNDWI 

MNDWI：改进归一化水体指数。该指数利用绿光与短波红外波段的反射差异，增强开阔水体特征，并减弱部分建筑、植被和土壤背景的干扰。

### 1. 基本原理

水体对短波红外辐射吸收较强，在该波段通常具有较低反射率；相比之下，绿光波段仍可能有一定反射。因此，许多水体像元的绿光反射率高于短波红外反射率。MNDWI 利用这种差异，使水体与周边地物更容易区分。

### 2. 计算公式

MNDWI = (ρGreen − ρSWIR1) / (ρGreen + ρSWIR1)

其中：

- `ρGreen`：绿光波段反射率。
- `ρSWIR1`：短波红外1波段反射率。

对于本作业使用的 Sentinel-2 数据

| 波段 | 含义 | 原始空间分辨率 |
| --- | --- | --- |
| B3 | 绿光 | 10米 |
| B11 | 短波红外1 | 20米 |

对应公式为：MNDWI = (B3 − B11) / (B3 + B11)

本作业先将影像波段值乘以 `0.0001`，转换为反射率，再进行计算；分母接近零的位置被屏蔽，以避免不稳定结果。

### 3. 数值如何理解

在两个波段反射率非负、分母不为零的情况下，MNDWI 位于 −1 到 +1 之间。

| 数值表现 | 一般解释 |
| --- | --- |
| 较高正值 | 开阔水体光谱特征通常较明显 |
| 接近0 | 绿光和短波红外反射率接近，需要结合影像判断地物 |
| 负值或较低值 | 常见于裸地、植被、建筑等非水体地物 |
水体与非水体之间没有适用于所有地区和时段的固定分界。浅水、浑水、湿泥、阴影、云雪和混合像元等均可能影响指数。因此，本作业保留连续指数，不使用“正值全部为水、负值全部无水”的简单规则进行分类。

## 五、对比图应该怎样读

两期指数统一使用 `−1` 至 `+1` 的显示范围，采用棕色—浅色—蓝色的连续色带。

| 图中颜色 | 含义 |
| --- | --- |
| 棕色、黄棕色 | 较低 MNDWI |
| 浅色 | 接近0的有效指数值 |
| 蓝色 | 较高 MNDWI |
| 洋红色 | 缺测，或分母接近零而被屏蔽的位置 |

洋红色仅用于显示缺测，不会写入原始 MNDWI 作为有效数值。**浅色与洋红色的含义不同：浅色表示有有效指数值，洋红色表示该位置无法参与有效比较。**

交互式地图左侧显示溃决前、右侧显示溃决后。比较时应拖动分隔线，观察同一地点在两个时段的变化。静态导出图则将相同范围的两期影像并排排列，并添加中文日期、色标和缺测图例。

根据当前对比图的目视观察，溃决后原库区内较高 MNDWI 的大面积分布明显收缩，许多位置转为浅色或较低值，部分河道及残余水体仍保留较高值。这一表现与水库退水、库底出露的已知事件过程相符，但浅色区域的具体地物仍需结合真彩色影像核验。

## 六、结果能说明什么，有哪些局限

本作业可用于直观展示溃决前后水体光谱特征及其空间分布变化。现阶段较合适的结果表述为：

> 基于 Sentinel-2 两期时段合成影像的 MNDWI 可视化对比，原卡霍夫卡水库区域较高指数值的分布范围在溃决后明显收缩，表明开阔水体特征显著减弱。该结果与大坝溃决后水库退水、库底出露的事件过程相符。部分河道及残余水体仍表现出较高指数值。
